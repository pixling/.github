# Support / サポート

Support is **best-effort**. We reply in **Japanese or English**; reports may be submitted in any language. We cannot promise a response time or a fix.
対応は **best-effort** です。返事は **日本語か英語**、投稿はどの言語でもかまいません。返答の期限や修正は約束できません。

- Documentation / ドキュメント: https://pixling.app/docs
- Bugs / 不具合: https://github.com/pixling/pixling/issues/new/choose
- Ideas and questions / 要望と質問: https://github.com/pixling/pixling/discussions (Ideas / Q&A)
- Billing, refunds, transaction IDs, wallet details, or personal circumstances / 課金・返金・取引 ID・財布の情報・個人の事情: [support@pixling.app](mailto:support@pixling.app)
- Security / 脆弱性: https://github.com/pixling/pixling/security/advisories/new (private / 非公開). If unavailable, email support. / 利用できなければサポートへメール。

Screenshots and logs can expose resident or agent conversations, file names, and your Mac account name. Review and redact before posting. Never post billing, refund, or transaction details in public issues or discussions.
画面・ログには住人・エージェントの会話・ファイル名・Mac のアカウント名が写りえます。投稿前に確認して伏せてください。課金・返金・取引の情報は公開の issue・discussion に書かないでください。

We do not use a stale bot or automatically close reports merely for inactivity. This intake repository does not accept pull requests; please use issues and discussions.
stale bot は使いません。動きがないだけで報告を自動的に閉じません。受付の repo では PR を受け付けません。issue・discussion を使ってください。
