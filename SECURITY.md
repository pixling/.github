# Security / 脆弱性の報告

**Do not disclose vulnerabilities in public issues or discussions.**
**脆弱性を公開の issue・discussion に書かないでください。**

Use [private vulnerability reporting](https://github.com/pixling/pixling/security/advisories/new). If it is unavailable, email [support@pixling.app](mailto:support@pixling.app) with a subject beginning `Security`.
[非公開の脆弱性報告](https://github.com/pixling/pixling/security/advisories/new) を使ってください。利用できなければ、件名を `Security` で始めて [support@pixling.app](mailto:support@pixling.app) にメールしてください。

Include the affected app version, a minimal reproduction, and the likely impact. Do not include credentials, personal data, resident or agent conversations, or unrelated files. Review screenshots and logs, including file names and Mac account names, before sending them.
影響を受けるアプリの版、最小限の再現手順、想定する影響を添えてください。認証情報・個人情報・住人やエージェントの会話・無関係なファイルを含めないでください。画面・ログは、ファイル名や Mac のアカウント名も含め、送る前に確認してください。

Handling is best-effort, with replies in Japanese or English. We cannot promise a response deadline. Please keep details private while we investigate and coordinate any disclosure with maintainers.
対応は best-effort、返事は日本語か英語です。返答の期限は約束できません。調査中は詳細を非公開にし、公開についてはメンテナーと相談してください。
